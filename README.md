Student Registration System

A web based Student Registration System developed using ASP.NET Web Forms and SQL server

Features
- Register new students
- View registered student details in a GridView
- Edit and Update student details
- Delete student records
- Generate student detail reports using RDLC reporting

Technologies used
- ASP.NET Web Forms
- C#
- .Net Framework
- SQL Server
- Microsoft ReportViewer(RDLC)

Configure SQL Connection
- Configure th SQL Server connection string in Web.config
